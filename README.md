# One Star for Monday

A one-star review of Monday, written as if Monday were a restaurant: a diner
orders the Monday special and gets a cold inbox, a warm laptop, and a waiter
who keeps refilling their deadlines.

The program (`main.py`) writes the single review line to `entry.txt` in the
output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).
